# Annihilation / COUNTERLEARN

[このゲームのコンセプト](spec/このゲームのコンセプト.md) に基づく、一人用の縦スクロールシューティングです。赤い弾を避け、青い弾を吸収して敵の攻撃を学習し、同種の弾をぶつけて対消滅を起こします。

C# / .NET 8 / raylib で実装しています。60秒の道中と複数パターンを持つボスで構成した1ステージを、開始からクリアまで遊べます。画像・音声素材の追加準備は不要です。

## 起動

1. Visual Studio 2022 の「.NET デスクトップ開発」と .NET 8 SDK を用意します。
2. このフォルダーの `Annihilation.sln` を開きます。
3. `Annihilation.Game` をスタートアッププロジェクトに設定し、Debug / x64 で F5 を押します。
4. タイトル画面で Enter を押します。

Windows x64 / OpenGL 3.3 対応環境を対象としています。Raylib-cs の NuGet パッケージにネイティブライブラリが含まれるため、C++ のビルドは不要です。

## 吸収・学習・対消滅

- **赤い敵弾**はフィールドでは防げません。**青い敵弾**も、フィールドを展開していないと被弾します。同じ種類の赤と青で、弾速・威力は変わりません。
- フィールドに時間制限、消費ゲージ、移動速度の低下はありません。低速移動は Shift の独立した操作です。
- 同じ種類の青い弾を一定数吸収すると学習できます。進捗は種類ごとに蓄積します。
- **保持できる攻撃は1種類だけ**です。新しい攻撃の習得時は前の武器を上書きし、各種類の途中の吸収数もリセットします。保持中の種類を再吸収しても武器は変わりません。
- 最初の学習後は C で学習弾を選んでください。新しい武器を習得しても現在のショットモードは維持します。学習弾は弾数・使用時間とも無制限です。
- **学習弾と同じ形の敵弾**がぶつかると、赤・青のどちらでも双方が消え、発射元の敵へカウンターが飛びます。発射元がすでにいない場合は、近くの敵を攻撃します。通常ショットや種類の違う弾では対消滅しません。
- ボムは3秒間、自機周囲の大きな範囲に入るすべての敵弾を対消滅させます。ボムで消した弾からは学習しません。

| 攻撃 | 習得に必要な吸収数 | 学習後の攻撃 | 対消滅1回の威力 |
| --- | ---: | --- | ---: |
| PULSE | 10 | 2連の直進弾 | 4 |
| FAN | 8 | 5方向の拡散弾 | 5 |
| SEEKER | 6 | 敵を追う誘導弾 | 8 |
| NOVA | 16 | ボス固有の3連弾 | 22 |

通常ショットは1発2ダメージ、学習弾の直撃は1発1ダメージです。NOVA は直撃より対消滅で特に大きな威力を発揮します。ボムのカウンターは種類を問わず1発2ダメージです。

## ステージ攻略

1. **APPROACH（0〜18秒）**：小型機をすぐに倒さず残すと、赤い PULSE の後に青い PULSE を撃ちます。ショットを止めて青い弾を集めるところから始められます。
2. **PURSUIT（18〜38秒）**：赤・青を切り替えて拡散弾を撃つ敵と、誘導弾を撃つ敵が混ざります。誘導弾はしばらく逃げると青に変わります。
3. **GATE（38〜60秒）**：プリズム砲台は自機弾を1発当てるたびに赤・青が反転します。望む色で射撃を止め、青い弾を撃たせられます。
4. **BOSS**：PULSE → FAN → SEEKER → NOVA の22秒周期です。予告表示と弾の形を見て、学習するか保持するか選びます。

NOVA 中は中央の青い連弾を吸収して16発集められます。習得したらフィールドを閉じ、別の種類を上書きしないように回避します。次の NOVA に学習弾を撃ち込むと、大きな対消滅カウンターを狙えます。中央以外にも別種の攻撃があるため、学習だけですべての弾が無効になるわけではありません。

ボスの耐久を0にするとステージクリアです。学習は必須ではなく、通常ショットだけでも撃破できます。残機は3、被弾後は2秒間無敵になり、敵弾を消去します。被弾しても学習武器と途中の学習進捗は維持します。残機0でゲームオーバーです。

吸収、学習、対消滅、敵の撃破でスコアを加算し、クリア時には残機・ボムの残数に応じたボーナスが入ります。ベストスコアはアプリ実行中のみ保持します。

## 開発・検証

このフォルダーをカレントディレクトリにして実行します。

```powershell
Set-Location C:\home\Dev\RaylibTest20260900\Shooting2
dotnet build Annihilation.sln -c Debug
dotnet run --project src/Annihilation.Game
dotnet build Annihilation.sln -c Release

# 描画不要の回帰テスト。失敗時は終了コード1。
dotnet run --project tests/Annihilation.Tests

# 非表示ウィンドウで実際のゲームを自動操作し、スクリーンショットを保存。
dotnet run --project src/Annihilation.Game -- --smoke-test
dotnet run --project src/Annihilation.Game -- --smoke-boss
dotnet run --project src/Annihilation.Game -- --smoke-title
```

テストは外部フレームワークを使わない23件のコンソールランナーです。`dotnet test` ではなく上記の `dotnet run` を使ってください。

描画検証の画像は `tmp/smoke-test.png`、`tmp/smoke-boss.png`、`tmp/smoke-title.png` に保存します。自動操作は通常の入力だけを使い、学習・残機・敵の耐久を直接変更しません。

| ファイル | 役割 |
| --- | --- |
| `src/Annihilation.Core/Entities.cs` | 入力、弾種、敵、演出のデータ |
| `src/Annihilation.Core/GameSettings.cs` | 速度、吸収数、威力などの調整値 |
| `src/Annihilation.Core/GameWorld.cs` | 移動、吸収、学習、対消滅、ボム、当たり判定 |
| `src/Annihilation.Core/GameWorld.Stage.cs` | 道中の配置、敵の挙動、ボスの攻撃パターン |
| `src/Annihilation.Game/Program.cs` | 入力、120Hz固定更新、起動・スモーク検証 |
| `src/Annihilation.Game/GameRenderer.cs` | ゲーム画面、HUD、操作説明、演出 |
| `src/Annihilation.Game/GameAudio.cs` | 外部素材を使わず生成する効果音 |
| `src/Annihilation.Game/SmokePilot.cs` | 描画検証用の自動操作 |
| `tests/Annihilation.Tests/Program.cs` | ゲームルールと状態遷移の回帰テスト |

画面は1040×840固定、ゲーム内表示は英語です。効果音は M で切り替えられ、音声デバイスがない場合もゲームを進められます。複数ステージ、セーブ、BGM は含みません。

依存ライブラリは Raylib-cs 8.1.0（raylib 6.0）です。バージョンと `packages.lock.json` を固定しています。
